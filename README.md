# 🌸 Wildflower

A flower decoration app built with React. Pick a flower, decorate it with a bow and save it to your account!

## Live Demo
[View on Vercel](https://vercel.com/violastan22-9572s-projects/wildflower-app/GpzaRgkUsSG2t2pNcTwAN7MRdNkW)

## Tech Stack
- React
- Node.js + Express
- JWT Authentication
- Jest + Testing Library
- Playwright E2E Tests
- GitHub Actions CI/CD

## How to run locally

### Frontend
```bash
npm install
npm run dev
```

### Backend
```bash
cd src/backend
npm install
node server.js
```

## Scripts
- `npm run dev` — start development server
- `npm run build` — create production build
- `npm run preview` — run built app locally
- `npm run lint` — check code quality
- `npm test` — run unit tests
- `npm run playwright` — run E2E tests
